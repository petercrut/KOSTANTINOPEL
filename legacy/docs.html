Dokumentasi API Kostantinopel

Kontrak REST API untuk sistem manajemen co-living — kost, kontrakan, apartemen, dan hotel. Mencakup autentikasi, properti, kamar, penyewa, booking, tagihan, laporan, pengumuman, analitik, portal penyewa, dan endpoint sistem. Setiap operasi menampilkan skema request, response, serta peran yang diizinkan.
